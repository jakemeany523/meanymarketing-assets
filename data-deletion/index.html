Data deletion instructions

This Threads app is a personal publishing tool. It stores no user data of its own: no database, no analytics, no copies of Threads content.

The only thing it holds is an access token, which lives in a local file on the operator's own machine and is used solely to publish posts and replies to the operator's own accounts.

How to have your data deleted

  1. Remove the app's access in Threads: Settings → Account → Website permissions, and revoke the app.
  2. Email the operator to confirm removal of any remaining token: jake@meanymarketing.com

On request, any stored access token for the requesting account is deleted and the request is confirmed by reply. Because the app keeps no other data, there is nothing further to erase.
